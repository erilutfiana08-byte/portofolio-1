Tentang Saya

Saya adalah mahasiswa aktif Program Studi Sistem Informasi semester 3 di Universitas Nusantara PGRI Kediri. Perjalanan saya di dunia teknologi didorong oleh rasa ingin tahu yang kuat untuk menciptakan aplikasi berbasis web yang estetis, terstruktur, dan berpusat pada pengguna.

Selain kegiatan perkuliahan, saya aktif belajar dan berdiskusi dalam komunitas koding SIKOKI. Melalui komunitas ini, saya mengasah kemampuan pemecahan masalah serta mendalami praktik terbaik rekayasa perangkat lunak modern.

Fokus saya saat ini tertuju pada Web Development dan UI/UX Design. Tujuan saya adalah terus belajar secara konsisten, membangun portofolio proyek yang solutif, serta siap berkontribusi dalam tim profesional melalui program magang industri.
